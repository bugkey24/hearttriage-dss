# Glossary

[![Docs](https://img.shields.io/badge/Docs-Glossary-blue?style=flat-square)](index.md)

</div>

| Term | Definition |
|------|------------|
| **DSS** | Decision Support System (Indonesian: Sistem Pendukung Keputusan / SPK) |
| **SAW** | Simple Additive Weighting |
| **Triage** | Prioritization of patients based on urgency |
| **Benefit** | Criterion where higher value is better |
| **Cost** | Criterion where lower value is better |
| **Normalization** | Scaling values to a common range |
| **Decision Matrix** | Table of alternatives × criteria |
| **Weight** | Relative importance of a criterion |
| **Alternative** | Option being evaluated (here: patient) |
| **P1** | Emergency triage level — immediate treatment (< 5 minutes) |
| **P2** | Urgent triage level — fast treatment (< 30 minutes) |
| **P3** | Non-urgent triage level — can wait (< 60 minutes) |
| **buff** | Dataset label meaning "healthy" |
| **sick** | Dataset label meaning "has heart disease" |
| **`cleve.mod`** | Cleveland Heart Disease dataset file (mixed format) |
| **MADM** | Multi-Attribute Decision Making — family of methods including SAW |
